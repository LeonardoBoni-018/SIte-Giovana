# Frames by Gi

Site de apresentação do **Frames by Gi** (fotografia mobile, videomaker e storymaker), com portfólio de trabalhos e contato direto pelo WhatsApp e Instagram.

🔗 **Online:** https://framesbygi.vercel.app

## Tecnologias

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Deploy na Vercel

## Estrutura do repositório

O projeto fica na pasta [`framesByGi`](./framesByGi). O guia completo de uso, estrutura de código e como adicionar fotos está em [`framesByGi/README.md`](./framesByGi/README.md).

## Como executar localmente

```bash
cd framesByGi
npm install
npm run dev
```

Para gerar o build de produção:

```bash
npm run build
npm run preview
```
